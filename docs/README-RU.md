# Personalized Post Bot - Фронтенд сервисы

> [English version](../README.md)

Эта директория содержит два фронтенд сервиса для платформы Personalized Post Bot.

## Компоненты

### MiniApp (`miniapp/`)

Tinder-style интерфейс для оценки постов в формате Telegram WebApp.

**Основные функции:**
- Swipe интерфейс для оценки постов
- Интеграция с Telegram WebApp API
- Поддержка темной/светлой темы
- Интеграция с API для загрузки постов и отправки взаимодействий
- Адаптивный дизайн для мобильных устройств

**Технологии:**
- HTML/CSS/JavaScript — Vanilla, без фреймворков
- Telegram WebApp API — Интеграция с Telegram
- Nginx — Статический файловый сервер

**Документация:** [miniapp/README.md](../miniapp/README.md)

### Admin Dashboard (`admin-dashboard/`)

Панель мониторинга для Personalized Post Bot со статусом сервисов, статистикой и управлением A/B тестами.

**Основные функции:**
- Мониторинг статуса сервисов
- Статистика пользователей и постов
- Настройка A/B тестирования
- Графики активности и метрики
- Безопасный доступ через SSH туннель

**Технологии:**
- HTML/CSS/JavaScript — Статический веб-интерфейс
- Nginx — Веб-сервер

**Документация:** [admin-dashboard/README.md](../admin-dashboard/README.md)

## Использование

### MiniApp

MiniApp доступен через Telegram WebApp и предоставляет swipe интерфейс для пользователей для оценки постов во время обучения. Требует HTTPS и должен быть развернут с публичным URL.

### Admin Dashboard

Админ-панель — это защищенный интерфейс мониторинга, который должен быть доступен через SSH туннель в production. Предоставляет комплексные возможности мониторинга и управления платформой бота.
