# MiniApp

> [English version](../README.md)

Tinder-style интерфейс для оценки постов в формате Telegram WebApp.

## Описание

MiniApp предоставляет swipe-интерфейс для пользователей для оценки постов во время обучения. Пользователи могут свайпнуть вправо для лайка, влево для дизлайка или пропустить посты. Интегрируется с Telegram WebApp API для аутентификации и темизации.

## Основные функции

- Swipe интерфейс для оценки постов
- Интеграция с Telegram WebApp API
- Поддержка темной/светлой темы
- Интеграция с API для загрузки постов и отправки взаимодействий
- Адаптивный дизайн для мобильных устройств

## Технологии

- **HTML/CSS/JavaScript** — Vanilla, без фреймворков
- **Telegram WebApp API** — Интеграция с Telegram
- **Nginx** — Статический файловый сервер

## Функционал

1. **Swipe интерфейс**
   - Свайп вправо → лайк
   - Свайп влево → дизлайк
   - Кнопки 👍/👎/⏭️

2. **Telegram WebApp**
   - Получение `initData` для авторизации
   - Тема из Telegram (dark/light)
   - `MainButton` для завершения

3. **API интеграция**
   - Загрузка постов из API
   - Отправка interactions

## Туннель для HTTPS

MiniApp требует HTTPS. Используйте Cloudflare Tunnel, localhost.run или production VPS с Let's Encrypt.
