# Admin Dashboard

> [English version](../README.md)

Панель мониторинга для Personalized Post Bot со статусом сервисов, статистикой и управлением A/B тестами.

## Описание

Админ-панель предоставляет веб-интерфейс для мониторинга сервисов бота, просмотра статистики, управления A/B тестами и доступа к аналитике. Защищена и должна быть доступна через SSH туннель в production.

## Основные функции

- Мониторинг статуса сервисов
- Статистика пользователей и постов
- Настройка A/B тестирования
- Графики активности и метрики
- Безопасный доступ через SSH туннель

## Технологии

- **HTML/CSS/JavaScript** — Статический веб-интерфейс
- **Nginx** — Веб-сервер

## Доступ через SSH туннель

Админ-панель не доступна публично из соображений безопасности. Для доступа используйте SSH туннель:

```bash
ssh -L 3000:localhost:3000 -L 8000:localhost:8000 root@your-server
```

После этого откройте http://localhost:3000 в браузере.

## Функции панели

- Статус всех сервисов (health check)
- Статистика пользователей и постов
- A/B тестирование алгоритмов
- Графики активности
