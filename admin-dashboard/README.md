# Personalized Post Bot - Admin Dashboard

> [Русская версия](docs/README-RU.md)

Monitoring dashboard for Personalized Post Bot with service status, statistics, and A/B testing controls.

## Overview

The admin dashboard provides a web interface for monitoring bot services, viewing statistics, managing A/B tests, and accessing analytics. It is secured and should be accessed via SSH tunnel in production.

## Key Features

- Service health status monitoring
- User and post statistics
- A/B testing configuration
- Activity graphs and metrics
- Secure access via SSH tunnel

## Technology Stack

- **HTML/CSS/JavaScript** - Static web interface
- **Nginx** - Web server
